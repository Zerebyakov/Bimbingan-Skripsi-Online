# Sistem Bimbingan Skripsi Online

Aplikasi web untuk mendukung proses bimbingan skripsi secara online.
Proyek ini juga menyediakan fitur untuk mendeteksi kemiripan makna
antarjudul skripsi melalui layanan machine learning berbasis Python.

## Fitur utama

- Proses bimbingan skripsi secara online
- Deteksi kemiripan makna judul skripsi

## Teknologi

- Frontend: React, Tailwind CSS
- Backend: Node.js, Express
- Database: MySQL
- Layanan machine learning: Python

## Struktur aplikasi

- `frontend/` — aplikasi antarmuka
- `backend/` — server dan API
- `ml-service/` — layanan machine learning
